# V47 / Proof-led Solutions design

**Prior art V44 rejected.** This implementation does not reuse its unrelated orbital art. V46 will inject the SINGLE verified V24 homepage sculpture into the V47 hero after the page content is built. Source HTML and pricing data are never touched.

## Information structure
1. Hero: recognizable pain, no generic service boasting.
2. Six business symptoms (lead quality, rising ads spend, content coherence, ownership, market expansion, team skill): diagnostic actions and tangible output for each.
3. Industrial machinery B2B worked *illustration*, clearly labeled **not an actual client success story**. Explain sources -> classification -> leak -> experiment. Never fabricate results.
4. Five service families (courses, ads, design-editor, remote-marketing, business-strategy), each with scope, actual artifacts and existing pricing link.
5. SOW and working process: evidence -> scope -> execution -> handover.
6. Single concluding lead CTA, no three simultaneous pitches.

## UX architecture
Editorial dark hero; neutral light problem section; dark worked example and practical file list; neutral service comparison; restrained dark workflow and ending. Avoid six oversized identical dark cards. Sections should feel distinguishable by purpose and evidence density.

## Contract
Every deliverable is conditional on scope, access, data, budget and client collaboration. No revenue guarantees, fictitious testimonials, case-study customers or numbers. Existing pricing source remains authority; project quantities/timelines need an approved SOW.

## QA
`npm run build`, 6 symptom cases × 3 locales, five pricing destinations per locale, actual artifact list, single true WebGL master art after V46, no horizontal overflow, one header/footer, Chromium screenshots and accessible action links. Branch PR targets V46 design foundation until it is approved; neither PR is in public website.
