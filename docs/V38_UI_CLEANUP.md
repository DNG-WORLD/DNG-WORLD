# DNGWORLD — V38 UI polish & repository cleanup

## Invariants
- Presentation-only: no changes to text, data, pricing, routes, translations, News & TV, contact details or V24 WebGL engine.
- V38 stylesheet is injected **last** into the generated GitHub Pages HTML. Original source HTML stays unchanged.
- All five pricing detail routes are smoke-checked in VI / EN / ZH.
- Older V25/V31/V33/V37 styles stay available for backward compatibility.

## UI
- Emerald/champagne color consistency, content widths, typography, card surfaces, button targets, focus and responsive spacing.
- Mobile breakpoints at 760, 520 and 380 CSS px; News & TV single-column article cards at narrow widths.
- Preserve WebGL geometry, camera, particle effects and animation logic.

## Repository hygiene
- `_site/` is generated by `npm run build` and uploaded by `.github/workflows/deploy-dngworld-pages.yml`; it is no longer versioned.
- Archived dated reports and old versioned READMEs are in `docs/archive/legacy-root/`; file blobs are unchanged and historical commits provide rollback.
- Do not remove source assets, data, Laravel archive, locale pages, pricing calculation logic, News & TV automation or active GitHub workflows.
- Existing CSS generations were deliberately not deleted without a complete live-use scan.

## Verification
```bash
npm run build
npm run check:ui
```
GitHub Actions validates this on a pull request. Compare routes /, /pricing/, five pricing pages, /insights/, /about/, /contact/ at 360, 390, 768, 1024 and 1440 CSS px.

## Rollback
Revert the V38 commit. If only the visual layer needs reverting, remove the post-build `polish-ui.mjs` / `check-ui.mjs` suffix from package.json's build command and rebuild. The original HTML and WebGL code are intact.
